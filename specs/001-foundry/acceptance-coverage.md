## Non-functional acceptance

Crash/restart each stage and confirm committed checkpoints survive (resumability); repeat unchanged input with no new findings/issues (idempotency); run structural fixture checks without a live model (determinism); inject each integration outage with visible backoff and unaffected work continuing (degradation); compare spend for the same target at different fleet sizes and investigate disproportionate growth (cost proportionality); reconstruct all publication provenance (auditability); surface persistence failures (no silent loss); apply and log explicit operator overrides; inject adversarial target instructions and confirm no privilege or authority change.
